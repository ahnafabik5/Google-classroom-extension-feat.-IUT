# 🎓 Classroom Command Hub

A modern, high-performance Manifest V3 Google Chrome extension built for IUT students to centralize Google Classroom courses, due assignments, past submissions, grades, and materials in a sleek obsidian-and-gold command center.

---

## ✨ Features

- **Automated Semester Filtering:** Automatically focuses on your current semester courses (hiding archived or previous semester courses).
- **Comprehensive 5-Column Dashboard:**
  1. **Course & Credit:** Direct links to your Google Classroom course pages with credit tracking (3.0 Cr / 1.5 Cr).
  2. **Due Tasks:** Active assignments with deadline badges and direct submission links.
  3. **Past Tasks:** Overdue or missed assignments tracked separately.
  4. **Submitted:** Completed work and grade tracking.
  5. **Materials:** Direct file attachments (PDFs, slides, code files) and post links.
- **Direct Links (`↗`):** Every course, assignment, and material links directly to its respective page on Google Classroom or Google Drive.
- **Secure OAuth2 Authentication:** Integrates directly with your institutional `@iut-dhaka.edu` Google account.

---

## 📥 Installation Guide for Classmates

Since this extension is configured for institutional IUT accounts, you can easily load it locally in developer mode:

1. **Download the Extension:**
   * Go to the GitHub repository [Releases](../../releases) (or download the repository as a `.zip` file using the green **Code** button).
   * Unzip/extract the folder on your computer.

2. **Load into Google Chrome:**
   * Open Google Chrome and type `chrome://extensions/` in the URL bar.
   * Turn on **Developer mode** using the toggle switch in the top-right corner.
   * Click the **Load unpacked** button in the top-left corner.
   * Select the extracted `classroom-hub` folder.

3. **Pin & Launch:**
   * Click the Extensions puzzle piece in your Chrome toolbar and pin **Classroom Command Hub** for quick access. Click the icon to open your live dashboard!
